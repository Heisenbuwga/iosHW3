# Discord「#一般」手機聊天頁

本次依提供的第三張 iPhone 截圖製作，重現標題、上線人數、日期分隔、彩色暱稱、身分標籤、@提及、回覆引文、黃色提及訊息與底部輸入列。頭像採自訂 Asset 圖片；暱稱、對話、提及與身分標籤皆為虛構內容，不沿用參考圖的私人訊息。

## 執行與展示

1. Xcode 26.6 開啟 iosHW3.xcodeproj，選 iosHW3 scheme 與 iPhone 17 Pro（iOS 26.5）。
2. Command-R 執行；訊息內容可上下捲動，標題和輸入列固定。
3. Simulator 的 Shift-Command-A 可切換深色與一般模式；ContentView 也包含兩組 Preview。
4. 捲到底部可點擊 Markdown 文字中的 Discord 連結。
5. 其他按鈕與輸入列為靜態展示，符合單頁作業範圍。

深色版以手機參考圖為依據；淺色版採前面桌面版參考的配色方向，尚未與手機淺色截圖逐項比對。

## 需求對照

| 作業需求 | 實作 |
| --- | --- |
| VStack、HStack、Text、ScrollView | ContentView、ChatMessageRow |
| ZStack | AvatarView、ChannelHeaderView 的未讀標記 |
| Image：Assets + SF Symbols | AvatarView 的圖片、標題與輸入列的系統圖示 |
| 多個 modifier | font、padding、background、overlay、frame、clipShape 等 |
| 上下捲動 | ContentView 的垂直 ScrollView |
| 多檔案 View | ChannelHeaderView、ChatMessageRow、MessageComposerView、AvatarView |
| property 客製 | channel、onlineCount、unreadCount、message、assetName、size |
| 明暗模式 | Asset Color Set 的 Any / Dark 配色 |
| Text Markdown 連結 | 聊天列表底部 Discord 連結 |

## 主要程式

- ContentView.swift：組合標題、訊息 ScrollView、輸入列。
- Models/ChatMessage.swift：作者、回覆及訊息資料。
- Views/ChatMessageRow.swift：可重用訊息列，以 AttributedString 製作提及樣式。
- Views/ChannelHeaderView.swift：頻道名稱、在線人數與未讀標記。
- Views/MessageComposerView.swift：靜態輸入列。
- Views/AvatarView.swift：可客製大小的 Asset 頭像。
- Models/DiscordTheme.swift：主題顏色；舊版訊息列表的資料與 View 保留但不再顯示。

發表可將第三張參考截圖與 discord-chat-dark.png 並排。裝置狀態列和可見訊息數會受 iPhone 型號與螢幕高度影響。
